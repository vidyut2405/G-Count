# 500 Club — Original Edition

This is the **original single-exercise, fixed 500-rep** experience (20 sets of 25 reps). It is intentionally not the later multi-exercise customizable edition.

## Vercel
Import this folder as a project with Framework Preset **Other**. No build command or output directory is needed. Vercel serves `index.html` at the root.

History is stored in the browser's localStorage. Google Fonts require network access. Wake Lock and audio are subject to browser permissions and support.
